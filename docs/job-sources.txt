JOB SOURCES USED BY JOB HUNTER
==============================

How each source reaches the app. Automatic access only where the site's terms and robots.txt
allow it (constitution principle V); everything else arrives through job-alert emails sent to the
user's job mailbox, or by pasting a link or the posting text.


1. AUTOMATIC SEARCHES (daily at 06:00 and "Import from all")
-------------------------------------------------------------

Job Bank (Government of Canada)
  https://www.jobbank.gc.ca/
  How:   official public search feed (Atom), one query per target-position title and Canadian place
  Rules: robots.txt allows access with a 5-second crawl delay; the app waits 5 s between requests
  Note:  the feed ignores the location, so the app filters places itself; few senior software roles

Company watchlist: public job boards of chosen employers
  Greenhouse   https://boards.greenhouse.io/<company>       API: boards-api.greenhouse.io
  Lever        https://jobs.lever.co/<company>              API: api.lever.co
  Ashby        https://jobs.ashbyhq.com/<company>           API: api.ashbyhq.com
  Workday      https://<tenant>.wdN.myworkdayjobs.com/<site> JSON behind the public career site
  Pinpoint     https://<company>.pinpointhq.com/            feed: <company>.pinpointhq.com/postings.json
  Rippling     https://ats.rippling.com/<company>/jobs      API: api.rippling.com (public job board API)
  JazzHR       https://<company>.applytojob.com/            feed: app.jazz.co/feeds/export/jobs/<company>
  Jobvite      https://jobs.jobvite.com/<company>/jobs      the public careers list itself (no feed)
  Eightfold    https://<company>.eightfold.ai/careers       public search API /api/pcsx (allowed by robots.txt)
  Phenom       the employer's own career site, e.g. jobs.rbc.com/ca/en   its public search page
  SuccessFactors the employer's own career site, e.g. jobs.rogers.com    its public search page
               (the sites' RSS feeds are under /services/, which their robots.txt disallows);
               newer "unify" sites (e.g. careers.deloitte.ca) build the list in the browser from
               /services/, so the app reads their full job feed at /sitemap.xml instead
  Oracle Cloud https://<host>/hcmUI/CandidateExperience/en/sites/<site>   its public job search
               (hcmRestApi), on *.oraclecloud.com or the employer's own domain
  BambooHR     https://<company>.bamboohr.com/careers       list: /careers/list, details: /careers/<id>/detail
               (robots.txt only disallows /jobs/embed*.php)
  HiBob        https://<company>.careers.hibob.com/         list: /api/job-ad with the companyIdentifier
               header the career site sends (no robots.txt)
  SmartRecruiters https://careers.smartrecruiters.com/<company>[?search=<words>]   the public careers
               page, its /api/groups and /api/more pages (jobs grouped by place) and each job's
               page for the description; api.smartrecruiters.com is never used (its robots.txt
               disallows all). ?search= keeps one brand of a group, e.g. Copperleaf at IFS
  How:   paste a company's careers link (a link to any one job works too; Phenom and
         SuccessFactors sites are recognised from that one page), or import a CSV of
         companies; boards on Greenhouse, Lever, Ashby, Pinpoint, Rippling, JazzHR and BambooHR are found
         through their public feeds (never the companies' own websites)
  Big employers (more open jobs than can be read in full, e.g. Medtronic, TD, RBC) are
         searched with each target-position title instead (Workday, Eightfold, Phenom,
         SuccessFactors, Oracle Cloud). Jobs listed as
         "3 Locations" (Workday) or "+3 more" (SuccessFactors) whose title fits are looked up
         once to get their places and description.
  Rules: official public feeds or the public search the career site itself uses; robots.txt
         is read as RFC 9309 defines it (most specific rule wins); at most 1 request per second per API
         host, 5 seconds between requests to the same careers site
  Not supported: Dayforce (its job search refuses requests from outside its own app), iCIMS,
         Taleo, sites behind a bot challenge (e.g. SAP)
         and companies' own sites (e.g. GlobalLogic);
         add those jobs by pasting a link or the posting text

Claude web search (optional, admin only)
  How:   "Find jobs with Claude" and a daily run: Claude searches the web for the target positions
  Rules: only WebSearch/WebFetch tools; LinkedIn, Indeed and Glassdoor pages are never fetched;
         results go through the same duplicate and place checks


2. JOB-ALERT EMAILS (to the user's job mailbox, checked every 15 minutes)
-------------------------------------------------------------------------

  LinkedIn     https://www.linkedin.com/jobs/      alerts go to the account's primary email
  Indeed       https://ca.indeed.com/              any email address per alert
  Glassdoor    https://www.glassdoor.ca/           alerts go to the account's email
  Job Bank     https://www.jobbank.gc.ca/          saved-search alerts
  Workopolis   https://www.workopolis.com/         saved as emails (no job extraction yet)
  Eluta.ca     https://www.eluta.ca/               saved as emails (no job extraction yet)

  How:   jobs listed in LinkedIn, Indeed, Glassdoor and Job Bank alerts become suggested jobs
  Rules: these sites forbid automated searching (Eluta's robots.txt disallows search and RSS),
         so alerts are the only automatic route; the app never logs in to them or stores their
         passwords


3. PASTE A LINK OR THE POSTING TEXT (any site)
-----------------------------------------------

  Pages are downloaded to pre-fill the form only for sources marked "may download" and only if
  robots.txt allows it:

  Job Bank         https://www.jobbank.gc.ca/                      download allowed
  GC Jobs          https://emploisfp-psjobs.cfp-psc.gc.ca/          download allowed
  Eluta.ca         https://www.eluta.ca/                           download allowed (single page)
  CharityVillage   https://charityvillage.com/                     download allowed
  Greenhouse, Lever, Ashby, Workday, Pinpoint, Rippling, JazzHR,
  Jobvite job pages                                                download allowed
  LinkedIn, Indeed, Glassdoor, Workopolis                          link saved, paste the text
  Any other site                                                   link saved, paste the text


4. COMPANY DIRECTORIES (to find employers)
-------------------------------------------

ABTEC 5000 (Technology Alberta)
  https://technologyalberta.com/abtec-5000/
  How:   browse it in a browser, or save the list as CSV and import it into the watchlist; the app
         then looks up each company's public job board
  Rules: the site is behind a bot challenge, so the app never downloads it


The admin can add, edit or disable sources under Admin -> Job sources (domains, "may download",
"sends job-alert emails").
